# 手写答卷转录协议

**这一步错，后面全错。** 低清图上误判一个词，会凭空造出一个错误标注，扣分结论也会跟着跑偏。

## 一、为什么低清图容易骗人

真实踩过的坑（2024.12 第 3 套新能源汽车）：

| 低清图判成 | 高清图实为 | 后果 |
|---|---|---|
| `now energy`（拼写错） | `new energy`（正确） | 多标 1 处拼写错 |
| `the develop`（词性错） | `the development`（正确） | 多标 1 处词性错 |
| `develop have developeds`（三个谓语） | `develop have` **被划掉** + `developeds` | 错误描述整个跑偏 |

三处误判，全部来自"没放大 + 没做交叉验证"。

## 二、标准流程

### 1. 先拿最好的图

如果用户给了多张，用最清晰的那张（通常是对焦准、正视角的）。**拿到更清晰的图，必须从头重核一遍，不要沿用旧转录。**

### 2. 定位手写区

```python
from PIL import Image
im = Image.open("page.jpg")
print(im.size)   # 先看尺寸，再决定裁切坐标
```

先看整图，目测手写区的大致范围（上、下、左、右边界），再裁一块预览，确认没有裁到页边。

### 3. 按行切分（关键）

**不要一次裁一大块**——图片缩放后字会糊。按行切，每行一张，放大 2–4 倍：

```python
from PIL import Image, ImageEnhance
im = Image.open("p.jpg")

# 先估行距：整段高度 ÷ 行数；起点用第一行基线
top, line_h = 690, 52
for i in range(n_lines):
    y0 = top + i * line_h
    c = im.crop((30, y0 - 10, 1590, y0 + 46))
    c = c.resize((c.width * 2, c.height * 2), Image.LANCZOS)
    c = ImageEnhance.Contrast(c).enhance(1.35)
    c.save(f"line{i:02d}.png")
```

**如果切出来发现每张都偏一行**，说明行距或起点估错了——用「内容对齐」校正：随便取一张，看它显示的是第几行，反推 `top` 和 `line_h`，再重切。不要凑合着读偏移的图。

更稳的办法是用水平投影自动找行：

```python
import numpy as np
a = np.array(im.convert("L"))[:, 1200:2050]
dark = (a < 110).sum(axis=1)     # 每行暗像素数
# 阈值扫描，连续 >8 的区间就是一行文字
```

### 4. 逐行读，但不要只信一遍

读完 13 行后，**通读拼接结果**，检查：

- 语义是否连贯（不通顺的地方多半是读错了）
- 冠词、单复数是否合理
- 有没有突兀的"多余字母"

### 5. 三处必须交叉验证

| 疑点 | 验证方法 |
|---|---|
| 拼写错（`new/now`、`rapidly/repidly`） | 找同一个词在别处的写法比对；两处都"错"才算错 |
| 划改（删除线 / 插入符） | 放大到 4 倍看是"横线穿过字"还是"下划线"；横线 = 删，下划线 = 强调 |
| 断行连字符 | 行尾的 `-` 是断词还是真连字符？看下一行开头是否接得上 |

### 6. 划改的判定

```
横线穿过文字中部  → 划掉（最终文本里不应出现）
字母上方小勾/插入 → 补充（最终文本里应出现）
单词中间一横      → 断词连字符（拼接时去掉）
```

判定后，在 `data.transcript` 里用 `<del>` 包裹划掉的部分，在 `tokens` 里用 `{"strike": true}`。

**重要**：划掉 ≠ 不存在。学生划掉 A 写 B，最终文本是 B；如果 A 是错的、B 是对的，要在 `why` 里肯定"划掉是对的"，而不是把 A 当成错误。

### 7. 存疑怎么办

实在看不清的：

- 优先找同类词的其他出现位置反推
- 仍然不确定 → 在 `why` 里写"此处字迹不清，按 XXX 判读"，**不要装作确定**
- 如果是核心信息（数字、专有名词），向用户确认

## 三、转录输出规范

1. **保留原始拼写**，包括错误（`repidly`、`goverment`）
2. **保留原始大小写**（`china` 小写要保留，这本身是错误）
3. **按手写换行**，一行一个字符串
4. **保留断词**：`produc-` + `tion` 按原样分两行，不要合并
5. **划掉用 `<del>`**，插入的词直接写进正文

## 四、常见陷阱清单

- [ ] 行距估错，读到了相邻行的一半
- [ ] 把上一行末尾的单词接到下一行开头（断词）
- [ ] 划掉的词当成正文
- [ ] 连笔 `r` 读成 `v`、`a` 读成 `e`、`o` 读成 `e`
- [ ] 复数 `-s` 没看到（`vehicle` vs `vehicles`）
- [ ] 冠词 `the` 漏读（手写常写得很小）
- [ ] `i` 的点被当成标点

## 五、验收

转录完成后，问自己三个问题：

1. 把转录文本从头读到尾，**通顺吗**？（不通顺 = 有错）
2. 每个"错误"我都能在图上**指出来**吗？（指不出 = 误判）
3. 划掉的部分，我确定是划掉而不是强调吗？

三个都过，再进 Step 3。
